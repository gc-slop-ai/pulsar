# Пульсар

Неоновый аренный twin-stick шутер в браузере. Чистый Canvas 2D, без зависимостей.

**Играть:** https://gc-slop-ai.github.io/pulsar/

- деформируемая пружинная сетка, которая реагирует на взрывы, рывки и гравитацию
- самодельный bloom (двухуровневое размытие), до 6000 частиц, виньетка, сканлайны, hit-stop и slow-mo
- 8 типов врагов: странники, охотники, делящиеся квадраты, дротики с прицелом, змеи, чёрные дыры (засасывают врагов, частицы, пули и тебя), искры
- босс «Квазар» каждые 6 волн: вращающийся щит из сегментов, спирали, кольца, залпы, таран
- бонусы «Веер», «Шквал», «Пробой», множитель за кристаллы, бомбы, рывок с неуязвимостью
- музыка и звуки синтезируются WebAudio на лету
- поддержка геймпада

## Управление

| | |
|---|---|
| WASD / стрелки | движение |
| мышь + ЛКМ | прицел и огонь |
| F | автоогонь |
| Shift / ПКМ | рывок |
| Пробел | бомба |
| P / Esc | пауза |
| M | звук |

Локально: `python -m http.server` и открыть http://localhost:8000
